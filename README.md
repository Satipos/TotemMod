# Totems Expansion

Fabric-only Minecraft **26.1.2** mod that adds three new totem variants.

## Totems

| Totem | Effect on lethal hit | Recipe |
|---|---|---|
| **Tornado Totem** | Launches nearby mobs into the sky; grants player Slow Falling + Resistance. | Totem of Undying + Wind Charge |
| **Fire Totem** | Deals 5 damage to mobs in 8 blocks, ignites them for 3 s; grants Fire Resistance. | Totem of Undying + Blaze Powder |
| **Cripper Totem** | Big AoE explosion (≈20 damage); user is immune (Resistance V + Absorption III). | Totem of Undying + TNT |

All totems act like a Totem of Undying — they save the player from death and consume one stack — but trigger their custom effect instead of the vanilla yellow overlay.

## Installation
1. Fabric Loader ≥ 0.19.2
2. Fabric API 0.146.1+26.1.2
3. Drop the mod jar in `mods/`.

## Creative tab
A dedicated **Totems Expansion** tab is added, containing the three totems plus their crafting ingredients for quick reference.
